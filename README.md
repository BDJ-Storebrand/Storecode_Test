# Job Compensation Comparison / Jobbkompensasjon Sammenligning

A web service to help people understand their total compensation (salary plus pension benefits) when evaluating job offers.

## What's Inside

A professional landing page featuring:
- Norwegian language content (Bokmål)
- Official Storebrand brand identity and colors
- Clean Scandinavian design aesthetic
- Information about the compensation comparison service

## Features

- **Total Compensation Analysis** - Compare salary and pension benefits side-by-side
- **Storebrand Branding** - Official colors and logo from Storebrand Brand Hub
- **Responsive Design** - Works on all devices
- **Professional UI** - Clean, trustworthy design

## How to View

Simply open `index.html` in your web browser.

## Design

Uses official Storebrand brand colors:
- Extra Dark Red (#560000) - Primary brand color
- Brand Red (#da291c) - Accent and CTAs
- Light Red (#ed554e) - Hover states
- Viera (#fffffa) - Backgrounds
